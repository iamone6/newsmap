/grill-me-with-docs
 다음 내용을 기반으로 postgresql dockerfile 와 db Schema 를 만들고자 해. 부족한 부분이 있으면 물어봐줘.

rag 를 위한 postgre schema 를 만들거야. 다음 내용을 보고 Dockerfile 을 만들고, db schema 를 만들어 줘.
    현재까지 결정한 사항:
    - 검색은 하이브리드 검색을 사용함.
    - postgre 와 플러그인으로 DB를 구성한다.
    - postgre 는 latest 의 버전을 먼저 확인하고, 해당 버전을 dockerfile 에 명시한다. 플러그인들은 해당 버전에서 지원하는 최신 버전을 사용하고 역시 해당 버전을 명시한다.

    1. 각 지역 뉴스의 정해진 RSS 를 cron 등으로 정기적으로 가져온다.
    2. 가져온 RSS 에서 기사 제목, URL, 발행일(없으면 created_at을 발행일로 취급), updated_at 을 가져온 뒤 각 기사에 대해 다음 작업을 진행한다.
        2-1. 기사의 URL 을 따라 이동하여 해당 페이지에서 기사제목, 부제목(가능한 경우), 본문, thumbnail url(있는 경우),  image url + caption 들(가능한 경우), canonical url 을 추출한다. 언론사명은 이미 가져오는 RSS 에서 지정되어 있다.
        2-2. LLM 으로 기사의 제목, 부제목, 본문을 보고 기사에 해당되는 지역이 어딘지 판단한다. 지역 구분은 시도, 시군구, 읍면동 단위까지 구분하되, 시도, 시군구, 읍면동 단위를 별도로 DB에 넣을 수 있도록 한다. 시군구, 읍면동 판단이 어려운 경우 null 로 처리하고, 지역과 무관한 기사르 판단되면 시도, 시군구, 읍면동 전체를 null 로 저장할 것이다. 지역 판단은 행정동 기준으로 진행할 것이므로, 행정동 코드에 매칭될 수 있는 지역명으로 리턴한다.
        2-3. LLM 으로 기사의 제목, 부제목, 본문을 보고 기자명(가능한 경우),언론사명(가능한 경우)을 추가로 추론할 수 있는 경우 추론한다. 언론사명의 경우 연합, 뉴시스 등과 같이 통신사나 라이센스에 문제가 될 소지가 있는 것을 걸러내기 위함으로 언론사명과 별도로 자사 생산 기사 여부를 저장하는 필드를 두어 자사 생산 기사면 null, 아니면 해당 언론사(통신사)명을 넣는다. (ex: 연합, 뉴시스)
        2-4. LLM 으로  각각의 image 에 대해 caption 을 살펴본다. 캡션에 별도 라이센스 표시가 있다면 역시 해당 이미지가 다른 언론사(통신사)의 이미지임을 알 수 있도록 필드가 있어야 한다.
        2-5. LLM 으로 해당 뉴스가 어느 섹션에 속하는지 판단한다. 대분류만 판단하면 된다. 다음 6개 중 하나 이상으로, 태그로 취급하여 복수로 관리가 가능하지만, 되도록이면 1개만 갖도록 한다. : 정치, 경제, 사회, 문화(생활, 연예 포함), 스포츠, 과학(IT 포함)
        2-6. 기사 제목, 부제목, 본문 등에 대해 HTML 태그, 특수문자를 제거한뒤 저장한다.
        2-7. 수집시각도 함께 저장한다.
        2-8. 중복 수집을 막기 위해 이미 가져온 기사들은 다시 처리하지 않도록 RSS별로 필터링한다. 생성일(created_at) 이 동일하고 updated_at 이 다른 경우에는 추가로 파싱하지 않는다.
        2-9. 
    3. 본문 청킹은 다음 기준(Recursive Character Splitter + Overlap) 을 따른다.
        3-1. 줄바꿈을 기준으로 청킹하는 것을 기본으로 한다.(Paragraph 기준)
        3-2. chunk size 는 500 토큰. 앞뒤로 10% 씩 오버랩.
        3-3. 청크가 몇번째 청크인지도 기록한다. 
        3-4. 청크에는 해당 지역, published_at(또는 created_at) 을 함게 포함하여 RAG 검색에 걸릴수 있게 한다.
    4. chunking/query 용 모델은 deepinfra.com 의 Qwen3-Embedding 0.6b 을 사용한다. api key 는 환경설정에 두어 소스코드와 frontend에 노출되지 않도록 한다.
